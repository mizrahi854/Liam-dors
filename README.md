# ליאם דלתות

האתר נבנה ועודכן: סליידר, התאמה לטאבלט, וידאו ונגישות. [הוראות וקוד האתר](site/README.md). [יומן הפעולות](יומן-עבודה.md).

הפעלה: `cd site` ואז `npm run dev`. הגלריה דורשת שרת HTTP; לא לפתוח את ה־HTML כקובץ מקומי.

## התיקיות
| תיקייה | תוכן |
|---|---|
| `assets/photos` | 41 תמונות מקור ו־3 תמונות הירו חדשות |
| `assets/videos` | 5 סרטוני מקור |
| `assets/references` | 3 תמונות רפרנס |
| `assets/video-previews` | 2 קטעי וידאו ערוכים לתכנון |
| `design` | הדמיות, פרומפטים ומיפויי מדיה |
| `design/review` | גליונות סקירת תמונות ופריימי וידאו |
| `design/source-photos` | עותקים קטנים שחולצו מהאיפיון, לא תמונות המימוש |
| `docs` | האיפיון הנוכחי ותוכן הלקוח |
| `docs/source` | האיפיון המקורי ללא שינוי |
| `docs/archive` | עדכון פלטה מהסבב הקודם |

קבצי המקור הועברו עם שמותיהם המקוריים ואומתו לפני ואחרי. ההדמיות נשמרו כהיסטוריית העיצוב. הקוד העדכני נמצא ב־site/dist והאיפיון העדכני הוא גרסה 3.
