# בדיקת פרסום GitHub Pages · 17.09.2026

כתובת: https://mizrahi854.github.io/Liam-dors/

## ממצאים
- לפני התיקון, HTML ו־CSS שפורסמו היו זהים לקבצים המקומיים.
- בהשוואה נקייה ב־Chromium, ארבעת קובצי הגופנים נטענו בשני האתרים, האייקונים הוצגו ולא נרשמו שגיאות JavaScript או HTTP. ההבדל שדווח לא שוחזר בסביבה זו.
- חלון דפדפן קודם שנשאר פתוח עדיין הציג את העיצוב הישן לפני רענון. אין להסיק מכך שזה היה מקור התקלה במכשיר המשתמש.

## תיקונים
- גאומטריית SVG מוטמעת ישירות בכל אייקון במקום הפניה לסמל משותף, עם מידות ותכונות קו מפורשות.
- נוספו text-size-adjust והגדרות כפתורים אחידות למניעת התאמות אוטומטיות של מנועי מובייל; זום והעדפות נגישות נשמרו.
- נוספו preload לגופנים העבריים וחתימות תוכן לכתובות הגופנים, CSS, JavaScript והקטלוג. הפניית הכניסה כוללת את גרסת העמוד ושומרת את ה־hash.
- נוסף .nojekyll כדי ש־GitHub Pages יגיש את האתר הסטטי ישירות.
- `npm run build` מעדכן חתימות ובודק את חבילת הפרסום לפני כל העלאה.

## בדיקות שבוצעו לאחר התיקון
Chromium וגם WebKit (מנוע Safari): רוחבים 320, 390, 768, 1024 ו־1440 — ללא גלילה אופקית, כל הגופנים נטענו, אייקוני החץ/ניגון/נגישות בעלי גאומטריה ומידות תקינות. נבדקו פתיחת הגלריה (41 תמונות), הגדלה, סגירה, חזרה ופתיחה/סגירה של התפריט. לא נרשמו שגיאות JavaScript או בקשות HTTP שנכשלו.

זו אינה בדיקת נגישות מלאה או בדיקה במכשיר iPhone פיזי. פרטי הקשר בהצהרת הנגישות עדיין ממתינים לבעל האתר.
