# LIAM — אתר הקטלוג

הקוד והמדיה המוכנים נמצאים ב־`dist/`. אתר סטטי ללא צורך בהתקנת חבילות. כל הגופנים והמדיה מקומיים.

## הפעלה

```sh
npm run dev
```

פותחים `http://127.0.0.1:8765`. חשוב להריץ דרך שרת HTTP, כי הגלריה טוענת `catalog.json`; פתיחה ישירה ב־file:// אינה מספיקה.

```sh
npm run check
```

בדיקות הקוד בודקות תחביר, קבצים, תוכן הלקוח, סדר תמונות, אייקונים ופרטי נגישות מבניים. הן אינן בדיקת דפדפן או אישור נגישות.

## מה השתנה

- סליידר: אפורה, ברונזה, גינה; כל 3 שניות. כותרות באנגלית וטקסט עברי נפרד מהתמונות. עצירה, בחירה, חיצי מקלדת והחלקה.
- התאמה לטלפון, טאבלט ומסך רחב; ב־700px וב־1100px הפריסה מתרחבת.
- כל הפקדים משתמשים באייקוני קו SVG, כולל פליי/פאוז, סגירה וחצים.
- וידאו ללא קול, בלולאה ובתוך העמוד, מתחיל כשהסקשן נראה ונעצר כשהוא יוצא. קיימת הפעלה ידנית אם הדפדפן או מצב חיסכון חוסמים אוטומציה. העדפת הפחתת תנועה מכובדת.
- תפריט מצומצם, סיפור דלת בגלילה והסברים טכניים לצד צילום. נשמרו כל טקסטי הלקוח, 16 תמונות מובילות ו־41 בגלריה.
- העדפות נגישות מקומיות, דילוג לתוכן, תיאורי מדיה, פוקוס ומסמך נגישות בטיוטה.

## קבצים לעריכה

- `dist/index.html`: תוכן, סדר הסקשנים ו־SVG.
- `dist/styles.css`: עיצוב ורספונסיביות.
- `dist/app.js`: סליידר, גלריה, וידאו ותפריטים. זמן ההחלפה הוא 3000 מילישניות.
- `dist/preferences.js`, `dist/accessibility.css`: העדפות תצוגה.
- `dist/accessibility.html`: מסמך נגישות; מחייב השלמת פרטי קשר ובדיקות לפני פרסום לציבור.
- `dist/catalog.json`: הגלריה והסדר הנבחר.

## מגבלות שנותרו

בוצעה בדיקת Chromium ו־WebKit ברוחבים 320–1440, כולל טעינת גופנים ואייקונים, גלריה ותפריט. ההבדל בין הגרסה המקומית ל־GitHub לא שוחזר בסביבה נקייה. נוספו התאמות דפדפן ומניעת ערבוב קבצים ישנים. בדיקת נגישות מלאה ובדיקות במכשירים פיזיים עדיין פתוחות.

## פרסום ל־GitHub Pages

מריצים `npm run build` לפני העלאה. מעלים את `site/dist` בשלמותו יחד עם קובץ הכניסה הראשי ו־`.nojekyll`. הגופנים מקומיים, האייקונים מוטמעים והסקריפט מעדכן חתימות תוכן כדי למנוע קבצים ישנים במטמון. חבילת הקוד כוללת את מבנה התיקיות המלא.

מקור הנחיות: [Skills IL — Israeli accessibility](https://github.com/skills-il/localization/blob/master/israeli-accessibility-compliance/SKILL.md), [מדריך הנציבות](https://www.gov.il/he/pages/declaration_website_accessibility?chapterIndex=1), [W3C — שליטה בקרוסלות](https://www.w3.org/WAI/tutorials/carousels/animations/).

## סיפור הדלת בגלילה

`dist/story.js` ו־`dist/story.css` מנהלים את רצף 15 הפריימים, סקשן הפרטים והסרטונים המדוברים. לוח המקור ב־`dist/media/story/door-storyboard.png`; גבולות הפריימים והמיפוי לתוכן נמצאים במערכי frames ו־shots. החלפתו מחייבת עדכון הגבולות. התוכן נגיש גם במצב הפחתת תנועה. אין צורך בהתקנת ספריות: GSAP/ScrollTrigger מקומיים בתיקיית vendor ונטענים רק בסמוך לסקשן. פירוט ותוצאות בדיקה ב־docs/תנועת-דלת-וסרטונים.md וב־docs/בדיקת-תנועה.md.
